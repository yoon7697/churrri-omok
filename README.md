# 우리 반 오목왕 v0.1

CHURRRI'S LAB의 첫 번째 교실 게임 프로젝트입니다.

## 현재 가능한 기능

- 따뜻한 크림색/파란색 반응형 메인 화면 (BGM 버튼, 학생 실명, 진행 상황 표시 제외)
- 15×15 로컬 2인 오목
- 흑돌 선공, 번갈아 착수, 마지막 수 표시
- 가로/세로/대각선 연속 5개 이상 승리
- 흑백 모두 3·3 금지: 서로 다른 두 방향에 동시에 열린 삼이 생기는 착수 금지
- 한 수 무르기, 새 게임, 규칙/사용 방법 안내

### 중요한 규칙 관련 안내

3·3 판정은 새 수를 둔 뒤 각 방향에서 한 수를 추가했을 때 양끝이 열린 연속된 4목이 되는지 검사합니다. 이어진 삼과 띄엄 삼을 포함하지만 **특수 금수 예외를 모두 검증한 공인 심판 엔진은 아닙니다.** 학교 공식 대회나 온라인 승패 처리에 사용하기 전 규칙 검증과 추가 테스트가 필요합니다.

## 아직 없는 기능

- 교사 방 만들기 / 방 코드 참가 / QR
- 컴퓨터 연습 AI
- 실시간 온라인 대국 / 관전 / 자동 매칭

버튼에는 '준비 중' 표시를 해 두었고 눌러도 실제 방이 생성되지 않습니다.

## 로컬 실행

`index.html`을 직접 더블클릭하면 ES 모듈 로딩이 브라우저에서 차단될 수 있습니다. 다음처럼 로컬 서버를 실행하세요.

```bash
python -m http.server 8080
```

그리고 `http://localhost:8080`으로 접속합니다.

## 검사

Node.js 20 이상에서:

```bash
npm test
```

## GitHub + Vercel 배포

1. GitHub에서 새 저장소(`churrri-omok`)를 생성합니다. 기존 포트폴리오 저장소와 분리하세요.
2. 이 폴더 내의 `index.html`, `styles.css`, `app.js`, `rules.js`, `package.json`, `README.md`, `assets/omok-hero.webp`를 구조 그대로 저장소 최상위에 업로드합니다.
3. Vercel에서 **Add New → Project → Import Git Repository**를 선택합니다.
4. Root Directory는 `./`, Framework Preset은 `Other`, Build Command는 비워두고 Deploy합니다.
5. 사이트가 뜨면 `1:1 대결`을 누른 뒤 한 기기에서 흑백 번갈아 착수 테스트를 진행하세요.
6. 완성 후 기존 [CHURRRI'S LAB](https://churrri-lab.vercel.app/)의 프로젝트 목록에 새 주소를 추가하세요.

이 버전은 백엔드나 개인정보 수집이 없는 정적 사이트로, 무료 Vercel Hobby 프로젝트로 테스트할 수 있습니다. 상업적 이용 조건은 별도로 확인하세요.
