# 우리 반 오목왕 v0.3.0 — 컴퓨터 연습

v0.2.1의 메인 일러스트, 로컬 2인 대결, 전용 게임 화면, 금수·승패 팝업을 유지하면서 컴퓨터 연습을 추가했습니다. 온라인 방·참가·대회 기능은 아직 구현하지 않았습니다.

## 사용 방법

- **연습하기** → 난이도와 내 돌 선택 → **연습 시작하기**
- 기본값은 **보통 / 흑돌**입니다. 백돌을 고르면 컴퓨터가 먼저 시작합니다.
- 컴퓨터가 생각하는 동안 착수는 잠깐 막히지만 메인 이동·새 게임·무르기는 작동합니다.
- 연습의 **내 차례로 무르기**는 컴퓨터 응답까지 취소합니다. 컴퓨터가 생각 중이라면 방금 둔 내 수만 취소합니다. 백돌로 연습할 때 컴퓨터의 첫 수는 유지합니다.
- 새 게임은 현재 난이도·돌 색을 유지합니다. 설정을 바꾸려면 메인 → 연습하기로 돌아갑니다.
- 1:1 대결의 한 수 무르기는 기존처럼 마지막 돌 하나를 취소합니다.

## 규칙

`rules.js`와 기존 28개 규칙 테스트는 v0.2.1에서 변경하지 않았습니다.

- 15×15, 흑돌 선공, 흑백 모두 3·3 금지
- 연속 5개 이상이면 승리, 5목 완성이 3·3보다 우선
- 4·4·장목 허용, 금수 착수는 무효이며 차례 유지
- 판이 가득 차면 무승부
- 예외적으로 컴퓨터의 합법 착수가 하나도 없으면 연습을 무승부로 종료합니다.

학교용 사용자 정의 규칙이며 공식 렌주 규칙과 다릅니다. 복잡한 3·3 예외 전부를 검증한 공식 심판 엔진은 아닙니다.

## 컴퓨터

| 난이도 | 방법 | 최대 탐색 깊이 | 탐색 시간 예산 |
| --- | --- | --- | --- |
| 쉬움 | 공격·방어 점수, 비긴급 상황에서 가끔 차선 선택 | 1수 | 점수 계산 |
| 보통 | 제한 후보 Minimax / Alpha-Beta | 2수 | 300ms |
| 어려움 | 반복 심화 Minimax / Alpha-Beta | 3수 | 900ms |

모든 난이도는 자신의 즉시 승리와 상대의 즉시 승리를 우선 확인하고, 열린 삼·열린 사·띄엄 패턴을 점수화합니다. 기존 돌 주변 두 칸을 후보로 삼으며 합법 후보가 없으면 전체 판을 검사합니다. 후보 수는 탐색 시 최대 8개이며, 기기 속도에 따라 끝까지 완료한 탐색 깊이를 사용합니다. 완전 탐색이나 무패 AI가 아닙니다.

계산은 모듈 Web Worker에서 실행합니다. 시간 예산은 탐색 노드 사이에서 확인하므로 마지막 노드 계산만큼 넘길 수 있습니다. 240ms의 짧은 생각 표시 후 시작하며, 5초 이내 응답이 없거나 Worker를 쓸 수 없으면 합법적인 기본 착수로 복구합니다. 최종 착수는 화면에서도 기존 규칙 엔진으로 재검사합니다. 무르기·새 게임·메인 이동은 Worker와 대기 타이머를 취소합니다.

## 실행 및 배포

런타임 외부 서비스·API 키가 필요 없는 정적 사이트입니다.

```sh
python3 -m http.server 8080
```

`http://localhost:8080`에서 확인합니다. 파일을 더블클릭하는 `file://` 방식은 모듈·Worker를 실행할 수 없습니다.

Vercel 설정: Framework Preset **Other**, 루트 `./`, 빌드 명령 없음, 출력 디렉터리 `.`. 기존 GitHub 연동을 유지할 수 있습니다. 기능 브랜치의 미리보기에서 확인한 뒤 main에 병합하면 운영 배포됩니다.

## 자동 검증

```sh
npm ci
npm test
npx playwright install chromium
npm run test:ui
```

규칙·AI 테스트는 Node의 기본 테스트 도구로 실행합니다. 화면 검증은 Playwright를 사용합니다. 설치된 Chromium으로 실행하려면 `CHROMIUM_PATH=/path/to/chromium npm run test:ui`를 사용할 수 있습니다. GitHub Actions에도 동일한 검증을 구성했습니다.

- 규칙·AI: 기존 규칙, 양 색·세 난이도 즉시 승리/방어, 금수 회피, 열린 삼/사 공격·방어, 판 보존, 시간 예산 종료, 합법 대국 진행, 무승부
- 브라우저: 실제 Worker의 여섯 설정 조합, 무르기·새 게임·메인 이동 중 취소, 로컬 금수/승리/무승부, 연습 결과, Worker 실패 복구
- 연습의 승리 팝업 시나리오는 컴퓨터 수만 고정한 테스트이며 실제 AI 대국 강도 검증과 구분됩니다.
- 화면 크기: 390×844, 768×1024, 1024×768, 1366×768, 844×390. 에뮬레이션 검증은 실제 iPad/Android 기기 테스트를 대체하지 않습니다.
