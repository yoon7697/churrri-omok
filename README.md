# 우리 반 오목왕 v0.2.1 — 태블릿 화면 전환 & 결과 팝업

이번 버전은 v0.2의 오목 규칙 엔진을 유지하고 **게임 화면 전환과 팝업만 수정**합니다.

- 홈에서 `바로 대결하기`를 누르면 스크롤하지 않고 전용 게임 화면으로 전환
- 게임 도중 페이지 스크롤을 막고 오목판에 `touch-action: none` 적용
- 3·3 금지 시 전용 팝업 + `닫기` 버튼 (금수 착수는 무효)
- 승리 시 전용 팝업 + `새 게임`, `처음 화면` 버튼
- 바둑판이 가득 찬 경우 무승부에도 동일한 종료 버튼 표시
- 규칙 안내/사용 방법 팝업과 로컬 2인 대전 유지

## GitHub에 반영할 파일

`index.html`, `app.js`, `styles.css`, `README.md`만 교체하면 됩니다. `rules.js`, `tests/`, `assets/`, `package.json`은 v0.2 그대로 유지할 수 있습니다.

## 실행

정적 웹사이트입니다. Vercel Framework Preset은 `Other`, 루트 디렉터리는 `./`로 두고 배포하세요. JavaScript 모듈은 로컬 파일 더블클릭보다 개발 서버에서 실행하는 것이 안전합니다.

## 테스트

`npm test` 실행 시 기존 v0.2 규칙 테스트를 사용합니다. 화면 전환과 팝업은 태블릿에서 실제로 클릭해 확인하세요.

### 주의

양쪽 3·3 금지는 학교용 간편 규칙으로, 렌주 공식 규칙과 다릅니다. 모든 복잡한 예외 상황까지 검증된 공식 심판 엔진은 아닙니다.
