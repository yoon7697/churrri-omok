## 교사 PC + 학생 태블릿 2대로 확인

같은 미리보기 주소를 사용하고 학생 한 명당 별도 기기·브라우저를 이용합니다. 여러 학생을 모을 필요는 없습니다. 다인 관전·부전승·40명 매칭은 위 자동 검사로 확인했습니다.

1. **교사:** 방 만들기 → 3라운드 선택 → QR코드 크게 보기.
2. **학생 2명:** 각 태블릿 카메라로 스캔 → 서로 다른 닉네임 입력. 교사의 오른쪽 참가 명단에 두 명이 보이는지 확인.
3. **교사:** 대결 시작. 학생은 상대 이름이 숨겨지고 흑·백 차례대로 착수되는지, 마지막 수가 빨간색으로 표시되는지 확인.
4. **복구:** 돌을 몇 개 놓고 학생 한 명과 교사의 화면을 새로고침. 같은 판·차례·남은 시간으로 복귀하는지 확인. 학생 와이파이를 잠깐 끊었다 연결하고 다시 확인.
5. **결과·다음 라운드:** 한 학생이 5목을 만들거나 교사가 무승부 종료. 상대 이름과 점수가 표시되고 교사가 다음 라운드를 시작하는지 확인.
6. **시간 종료·대회 종료:** 한 라운드를 5분 동안 두어 시간 만료 후 무승부 1점씩인지 확인. 남은 라운드는 교사가 종료해 최종 공동순위와 새 방 만들기를 확인. 테스트 후 방 닫기.

이 과정을 학교 와이파이에서 확인하면 됩니다. Safari/iPad 실기기 호환성, 실제 카메라 인식, 40대 동시 사용 성능은 자동 브라우저 검사와 구분합니다.

## 운영 시 기억할 제한
